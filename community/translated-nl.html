Introduction

GTXConv is a utility to generate AmigaE source code from a GUI file created by GadtoolsBox 2.0+. SrcGen was the basis for this program.

GTXConv capabilities:

  • has a user-friendly and fully multitasking GUI
  • generates compileable code or only desired routines
  • generated code is compatible with AmigaE v2.1b and v3.x
  • is fully configurable
  • low memory usage
  • all tags, idcmps, flags, gadgets etc. are recognized
  • can handle custom, public and workbench screens
  • generates font-sensitive code
  • Can use system or text fonts when generating font-sensitive code
  • supports Powerpacked GUIs
  • checkbox gadgets may be resizable under v39+ (as well as radio buttons)
  • the 'Newlook' can also be used for menus
  • full support for keyboard
  • IDCMP and flags can be as hexadecimal or as a keyword
  • is shown.
  • GETFILE custom gadget is supported

This program is written in AmigaE v2.1b. Right now, I intend to:

  • multitasking support
  • GTXConv to locate
  • Improve Layout generated code (indent)
  • Add all TAGS missing in this version

TECHNICAL INFORMATION

All tags, idcmps, flags, gadgets (yes, even the GETFILE type!) are supported. Not all v39+ tags are supported by GTXConv because they are (yet?) not supported by GadToolsBox. As a certain tag is not yet present in a future version are added.

Be warned at ListView gadgets: They are generated but labels and string gadgets are not supported (GTLV Labels and GTLV SHOWSELECTED are present in the code but with NIL argument). This Not my fault, but GadToolsBox's: You can get the stringgadget for do not select the listview. In addition: in the autodoc are quite Some bugs. I will try to restore this in a future (in the far future version. So, if you want to add a stringgadget in a listview: replace the NIL argument of GTLV SHOWSELECTED with the tag of the stringgadget you want to add. Simple? If you don't know how to handle a ListView gadget, in the gtlv.e example of the AmigaE distribution is pretty good Described how to do that.

THE GETFILE GADGET

From version 1.3 GTXConv is able to get the GETFILE gadget into the source (b) to be recorded. The GETFILE gadget is no ordinary gadget but a boopsi Gadget, a gadget that is not automatically generated by GadTools. The picture and the code needed for the GETFILE gadget is in the 'boopsi.m' module present in the GTXConf archive. This module cannot be read by AmigaE v2.1b, but by AmigaE v3+ (let's register with Wouter van Oortmerssen). But don't be desperate. I'm making a v2.1b version. To get the GETFILE gadget you have to copy the 'boopsi.m' module to your EMODULES: directory. And that's all! But remember that this gadget fontsensitive, so do not use the fontsensitive code option if there is a GETFILE gadget in your GUI. Finally, The GETFILE code has the utility.library v37+ needed in your LIBS: directory. Because that's a system library, it wouldn't. must be a problem...
